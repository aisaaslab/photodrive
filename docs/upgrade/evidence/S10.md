# Evidence: Sprint 10 (engagement features)

## S10-01 Selection export (2026-11-27)

- `lib/gallery/selection-export.ts`: one pure formatter for the owner endpoint and the "Copy filenames" button, so both give the same text.
  Natural sort (IMG_2 before IMG_10), optional extension stripping, CSV with header, CRLF and quoting.
- `GET /api/galleries/[id]/selection/export?format=txt|csv&ext=keep|strip`: gallery owner only; anyone else (other user, anonymous, missing gallery) gets the same 404; `Cache-Control: private, no-store`.
- Favorites dialog: "Without file extensions" option (applies to Copy and CSV) and a "Download CSV" link; six languages.
- Proof: `tests/selection-export.test.ts` (9 unit tests) and `tests/security/selection-export.emu.test.ts` (5 tests against the Firestore emulator, including non-owner 404).
- Not run: the browser dashboard snapshot (the dialog gained two controls, so its baseline text changes when next regenerated).
