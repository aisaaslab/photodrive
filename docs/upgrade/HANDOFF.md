## 6 · How to work in this repository

**Setup and commands**

```bash
git fetch origin claude/beautiful-archimedes-vsqbhq && git checkout claude/beautiful-archimedes-vsqbhq
npm ci
npm run lint -- --max-warnings 11   # CI cap: do not add warnings (11 existing)
npm run typecheck && npm test       # 334 unit tests
npm run i18n:check                  # key/placeholder parity of the six dictionaries (CI)
npm run test:emu                    # Firestore/Auth emulator suite (needs Java 21 for the emulators)
npm run build
```

**Next.js here is not the one you know** (Next 16): read the relevant guide in `node_modules/next/dist/docs/` before using a Next API (see `AGENTS.md`).

**Browser checks** (Playwright, real browser, no credentials, emulators only): everything in `scripts/verify/browser/`, described in its `README.md`.

```bash
npm run emu &                                                    # Auth 9099 + Firestore 8080
NEXT_PUBLIC_FIREBASE_EMULATORS=1 NEXT_PUBLIC_FIREBASE_PROJECT_ID=demo-photodrive NEXT_PUBLIC_FIREBASE_API_KEY=fake-key npm run build
scripts/verify/browser/emu-reset.sh --plans                      # wipe + seed (use --plans for the pricing check)
scripts/verify/browser/serve-emu.sh                              # production server on :3997 with a Drive stand-in
export NODE_PATH=$(npm root -g)                                  # Playwright is installed globally in the cloud sandbox; else `npm i -D playwright`
WITH_PLANS=1 npx tsx scripts/verify/browser/landing.cjs          # new landing: 70+ checks, six languages, three widths
node scripts/verify/browser/lp.cjs                               # /lp/* pages
SHOT=/tmp/shots AXE_PATH=/path/to/axe.min.js node scripts/verify/browser/user-area-shots.cjs   # user-area screenshots + axe (18 screens, 2 widths)
node scripts/verify/browser/user-area-langs.cjs                  # long-text overflow check, five languages at 390 px
npx tsx scripts/verify/browser/i18n.cjs                          # one language per page, server-rendered, cookie
# for the UI primitives check start the server with: SHOW_DEV_UI=1 scripts/verify/browser/serve-emu.sh
node scripts/verify/browser/ui-primitives.cjs
```

Reset and reseed before each snapshot run (`gallery-snapshot.cjs`, `dashboard-snapshot.cjs`, never both without a reset in between: they change the data); `diff` the output with `scripts/verify/browser/baselines/` (identical = a refactor changed nothing a
visitor can see; update the baseline deliberately when the UI is meant to change). Never use real Stripe, Firebase or Google credentials in a test.

**Conventions (from `NEXT-SESSION.md` and `AGENTS.md`)**

- The plan is the source of truth. Work **one task at a time**; update the checkbox **in the same commit**: `node docs/upgrade/tools/status.mjs start|done <ID>`.
- Test first for payments; dry-run first for anything that writes user data; record decisions with ids; do not widen scope (park it in the sprint file).
- Ask the owner before outward-facing or irreversible actions. **Never put live Stripe keys in a session, log or commit.**
- Evidence for each task goes in `docs/upgrade/evidence/S*.md`. Commit messages end with the `Co-Authored-By` / `Claude-Session` trailers your platform gives you.
- Pull requests: do not open a new one; push to PR #8's branch. The PR stays a **draft** until the owner signs off.
- i18n: dictionaries are `lib/i18n/dictionaries/{en,el,nl,de,es,it}.ts` (`en` defines the type). New landing copy lives under `landing` and is written with
  `python3 scripts/i18n/set-section.py <section> <json>` (idempotent). Non-English wording is draft until a native speaker reviews it.
- Design: tokens in `@theme` in `app/globals.css`, documented in [`design-tokens.md`](design-tokens.md); primitives in `components/ui/`; landing in `components/landing/`;
  all primitives show their states on `/dev/ui` (404 in production unless `SHOW_DEV_UI=1`).
